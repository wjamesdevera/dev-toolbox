# Dev Toolbox

A personal, ready-to-use collection of Markdown templates, multi-language code snippets, and standard project configurations designed to eliminate repetitive setup and boilerplate.

## 🛠️ What's Inside

```text
.
├── configs/          # Dockerfile, .gitignore, tsconfig, CI/CD workflows
├── docs/             # ADR, API docs, system design, and setup guides
├── snippets/         # Reusable scripts, utility functions, and patterns
└── templates/        # README, CONTRIBUTING, ISSUE_TEMPLATE, and PR guides
```

- `configs/` — Standard setup files for Docker, environment configs, and tooling.

- `docs/` — Architecture Decision Records (ADRs), onboarding docs, and technical specifications.

- `snippets/` — Self-contained helper code, shell scripts, and common algorithms.

- `templates/` — Structural Markdown scaffolding for rapid project bootup.

## ## ## ## ## ## ## ## ## 🚀 Usage

1. Browse or Search: Find the file or snippet you need via the directory structure above.

2. Copy & Paste: Grab the raw Markdown or code directly into your destination project.

3. Customize: Replace placeholder parameters (e.g., <PROJECT_NAME>, [TODO]) with your specific implementation details.
